# BLACKLINE BARBERS

True multi-page React/Vite barbershop demo.

## Pages
- `/` — Home
- `/services` — Services & prices
- `/barbers` — Barbers
- `/gallery` — Gallery
- `/about` — About
- `/booking` — Booking

## Stack
React + Vite + React Router + SCSS + Lucide React

## Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The included `vercel.json` enables direct navigation to React routes on Vercel.
